Sessions that outlive you

Walk away. Nothing stops.

Every chat runs in its own tmux session on the machine it belongs to. Harbor only attaches to it. Quit the app, lose Wi-Fi or close the lid, and the agent never notices.

  • Quit or close the window. Chats keep running. Reopen Harbor and every tab reattaches.
  • Network drops. Harbor reattaches automatically, without restarting the agent.
  • Resume anything. Every chat keeps its exact Codex or Claude conversation ID, so even after a reboot you pick up the same conversation.
  • Nothing to import. Harbor finds the conversations you already started in a plain terminal.

Know when to come back

Come back only when you’re needed.

Handing off work is half the job. The other half is not checking every tab to see what happened.

  • Working the agent is mid-turn
  • Needs input waiting on your approval or answer
  • Background work the turn ended, but jobs it started are still running
  • Turn finished ready for your next prompt

Desktop notifications, unread dots and a Dock badge tell you what changed. ⌘J jumps straight to the next chat that needs you. Fold everything away and Harbor shows one overview of every open chat.

Tabs, the way you already use them

If you can organize a browser, you already know Harbor.

Harbor borrows the tab habits power users have built over years of daily browsing: groups, folding, split view, focus. There’s no new mental model to learn. Your chats simply behave like the tabs you already organize every day.

Tab groups
Chats group by project automatically, each in its own color. ⌘-click a few tabs and press ⌘G for a group of your own.
Collapse a group
Fold a group into a chip. It still shows its most urgent status, so nothing that needs you goes quiet.
Split view
Drag a tab onto a pane’s edge. Split tabs stay linked in the tab bar, like Chrome’s split view.
Focus
Focus mode keeps only the current group open; click another chip to switch.
Shortcuts you know
⌘1–9, ⌃Tab, ⌘W, drag to reorder, tabs that shrink before they scroll.
Try it Fold a group, drag a tab onto the terminal to split, ⌘- or Shift-click tabs to group them, or turn on Focus mode. The agents are simulated and keep working while you play.

Both agents, side by side

Codex and Claude Code, first-class.

Start either one from the same place with ⌘N. Both share the sidebar, the status icons and the notifications. Put them in adjacent panes, and let one review what the other wrote.

  • Real terminals. Each chat is the agent’s own CLI, not a wrapper around it. Your config, credentials and history stay exactly where they are.
  • Fork a chat to try a different approach without disturbing the original.

Your Mac and your servers

Every machine, one sidebar.

A project is a folder on a host: your Mac, a build server, a GPU box. Harbor reaches them over plain SSH and runs each agent right next to its code.

  • Import hosts from your SSH config. Harbor never edits it.
  • Browse remote folders with a quick picker when you add a project.
  • Drop files onto a remote chat and Harbor copies them to the server for you.
  • Open in Cursor locally or over Remote-SSH, with the same connection settings.

And also

  • Notes and to-dos on any chat or project, in Markdown.
  • Search chat names with ⌘K and scrollback with ⌘F.
  • Rename and pin chats; names you set stick.
  • Launch commands for every chat, ready to copy.
  • Agent updates checked on every host, with one-click update.
  • Permission modes per agent, from read-only to full access.

Install

Get started in a few minutes.

  1. Download Harbor and move it to Applications. Download link coming soon
  2. Install tmux 3.2+ on your Mac and on each server: brew install tmux
  3. Install and sign in to Codex and/or Claude Code wherever you want to run them.
  4. Set up SSH keys for your servers, then import them in Preferences → Hosts.

Requirements

  • macOS on Apple Silicon
  • tmux 3.2+, Python 3.8+ and bash on each host
  • Codex and/or Claude Code, installed and signed in
  • Key-based SSH for remote machines
